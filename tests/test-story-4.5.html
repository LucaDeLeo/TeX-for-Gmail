🔧 Safe Abbreviation Patterns (When Enabled)

New safe abbreviation syntax that won't collide with standard LaTeX commands.

Note: Abbreviations are now disabled by default to prevent conflicts. Users can enable them in settings if desired. When enabled, only the safe patterns below will work.

Blackboard Bold

\bb{R} → \mathbb{R}
\bb{N} → \mathbb{N}
✓ Safe: Requires braces

Bold Face

\bf{x} → \mathbf{x}
\bf{vector} → \mathbf{vector}
✓ Safe: Won't match \beta

Calligraphic

\cal{L} → \mathcal{L}
\cal{F} → \mathcal{F}
✓ Safe: Won't match \cdot

Fraktur

\frak{g} → \mathfrak{g}
\frak{M} → \mathfrak{M}
✓ Safe: Won't match \frac

Wide Tilde

\tilde{x} → \widetilde{x}
\tilde{AB} → \widetilde{AB}
✓ Safe: Standard syntax

Overline

\bar{z} → \overline{z}
\bar{AB} → \overline{AB}
✓ Safe: Standard syntax
