# Story 4.5: Fix LaTeX Abbreviation Command Collisions

## Status
**Status:** Ready for Review

## Story
As a TeX for Gmail user, I need LaTeX commands like \frac, \cdot, \beta, and \begin to render correctly without being corrupted by the abbreviation expansion system, so that my mathematical equations display properly.

## Acceptance Criteria
1. ✅ Standard LaTeX commands (\frac, \cdot, \beta, \begin, \dot, \underline, \omega, \forall) render correctly
2. ✅ Abbreviation patterns are replaced with safe, brace-required versions that don't collide
3. ✅ Abbreviations are disabled by default with a settings toggle to enable them
4. ✅ When enabled, safe abbreviations like \bb{R}, \bf{x}, \cal{L} work correctly
5. ✅ Test file demonstrates all fixed commands work properly

## Dev Notes
The bug was caused by overly aggressive regex patterns in the abbreviation expansion that were matching the first letters of legitimate LaTeX commands:
- `\frac` was becoming `\mathfrak r ac` (rendering as "rac")
- `\cdot` was becoming `\mathcal d ot` (rendering as "ot") 
- `\beta` was becoming `\mathbb e ta` (rendering as "ta")
- `\begin` was becoming `\mathbb e gin` (causing "Invalid Equation")
