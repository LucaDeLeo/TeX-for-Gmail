# Story 5.4 Storage Migration & Font Validation Improvements

## Story
As a TeX for Gmail user
I want consistent settings across tabs and flexible font options
So that my preferences work reliably and I can use my preferred fonts

## Status
Proposed

## Epic
Epic 5: Critical Bug Fixes & Stability

## Priority
P2 - Enhancement

## Description
Improve storage migration consistency between sessionStorage and chrome.storage across tabs. Loosen font validation to support more user-provided fonts beyond the strict allowlist. Add proper state synchronization when settings change.

## Technical Context
Server preference migration can momentarily disagree across tabs. Font allowlist is too strict, causing many valid fonts to fall back to "serif". No broadcast mechanism for setting changes across tabs.

## Acceptance Criteria
1. Storage migration synchronized across all tabs:
   - Use runtime.onMessage for tab broadcast
   - Settings changes propagate immediately to all tabs
   - No momentary inconsistencies during migration
2. Font validation improved:
   - Expand allowlist to include common system fonts
   - Allow user-specified fonts with validation
   - Provide clear feedback when font falls back
3. Settings changes apply immediately without page reload
4. Storage operations include proper error handling and retry logic
5. Migration state tracked to prevent duplicate migrations

## Implementation Details
- Implement message broadcasting for storage changes
- Create comprehensive font allowlist or validation logic
- Add storage operation wrapper with error handling
- Track migration state in storage to prevent re-runs
- Use chrome.storage.onChanged listener for real-time updates

## Test Plan
1. Test multi-tab synchronization:

3. Test storage migration:

6. **Error Handling Pattern**:
   ```javascript
   async function storageOperation(operation, retries = 3) {
     for (let i = 0; i < retries; i++) {
       try {
         return await operation();
       } catch (error) {
         if (i === retries - 1) throw error;
         await new Promise(resolve => setTimeout(resolve, 100 * (i + 1)));
       }
     }
   }
   ```
