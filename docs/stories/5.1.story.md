# Story 5.1 Fix Missing Functions & Unified Toggle State Model

## Story
As a TeX for Gmail user
I want continuous rendering modes to work reliably without errors
So that I can use keyboard shortcuts for automatic LaTeX rendering

## Status
Proposed

## Epic
Epic 5: Critical Bug Fixes & Stability

## Priority
P0 - Critical

## Description
Fix broken function references that prevent continuous rendering modes (Cmd/Ctrl+F8/F9) from working. Unify the toggle state model to use consistent enum values instead of mixed boolean/string types. Standardize toolbar element keying to ensure buttons are found correctly across all modes.

## Technical Context
The codebase references undefined functions (`setupContentObserver`, `removeContentObserver`, `restoreOriginalContent`) that should map to existing implementations. The toggle state uses both boolean and string values, causing type confusion and incorrect UI states.

## Acceptance Criteria
1. Replace all broken function references with correct implementations:
   - `setupContentObserver` → `setupAutoRenderObserver`
   - `removeContentObserver` → targeted observer disconnect or `performComprehensiveCleanup`
   - `restoreOriginalContent` → `restoreLatexSource`
2. Implement unified toggle state as enum `'off' | 'api' | 'simple'` across all functions:
   - Update `getToggleState`, `setToggleState`, `toggleRendering`
   - Update `detectAndRenderLatex`, `updateButtonVisualState`
3. Standardize toolbar element keying so `toggleContinuousMode` finds buttons stored by `addTexButton`
4. Cmd/Ctrl+F8 and Cmd/Ctrl+F9 successfully enable continuous modes without errors
5. Toggle button visual state always matches actual rendering state
6. No console errors when switching between rendering modes

## Implementation Details
- Search for all references to missing functions and replace with correct ones
- Create a `ToggleState` enum or constants object
- Refactor all state management to use the unified enum
- Add type checking/validation in state getters/setters
- Ensure toolbar lookup uses consistent selectors

## Test Plan
1. Test continuous mode activation via Cmd/Ctrl+F8 and Cmd/Ctrl+F9
2. Verify observer attachment and detachment work correctly
3. Test toggling between off/api/simple states
4. Confirm button visual state matches actual state
5. Test with multiple compose windows open
6. Check console for any errors during mode switches
