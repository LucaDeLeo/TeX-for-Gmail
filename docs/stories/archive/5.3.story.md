# Story 5.3 UI State Consistency & Visual Polish

## Story
As a TeX for Gmail user
I want consistent visual feedback and reliable UI behavior
So that I always know the current rendering state and can trust the interface

## Status
Proposed

## Epic
Epic 5: Critical Bug Fixes & Stability

## Priority
P2 - Enhancement

## Description
Ensure all UI state changes route through centralized update functions for consistency. Fix inline style `!important` usage that doesn't work in JavaScript. Add debouncing to Copy LaTeX button to prevent flicker. Document regex assumptions and improve currency detection edge cases.

## Technical Context
Direct style mutations bypass `updateButtonVisualState`, causing visual drift. JavaScript `style.display = 'inline-flex !important'` doesn't apply `!important`. Copy button reparenting causes flicker on rapid hover.

## Acceptance Criteria
1. All button/label state changes route through `updateButtonVisualState`:
   - No direct style mutations in continuous mode paths
   - Consistent aria-pressed attributes
   - Label text always matches actual state
2. CSS `!important` declarations moved from JavaScript to stylesheets
3. Copy LaTeX button includes hide debounce (100-200ms) to prevent flicker
4. Code comments document Chromium-specific regex requirements
5. Currency detection handles edge cases correctly:
   - `$9.99`, `$10-$20`, `$5 each` not rendered (currency)
   - `$1 + 1 = 2$` is rendered (math)

## Implementation Details
- Create centralized UI update functions
- Move all `!important` rules to CSS classes
- Implement debounced hide for Copy button
- Add comprehensive code comments for regex patterns
- Review and refine currency detection logic

   - **Algorithm refinement needed**:
     ```javascript
     // Improved currency detection
     const isCurrency = (text) => {
       // Price ranges: $10-$20, $5-10
       if (/\$\d+[-–]\$?\d+/.test(text)) return true;
       // Prices with text: $5 each, $10 per
       if (/\$\d+\.?\d*\s+(each|per|for|only)/.test(text)) return true;
       // Simple prices: $9.99
       if (/^\$\d+\.?\d*$/.test(text.trim())) return true;
       return false;
     };
     ```

3. **Button State Management**:
   - Current visual state updates at lines 612-619:
     ```javascript
     button.setAttribute('data-tooltip', 'LaTeX rendering is ON...');
     button.innerHTML = '📐 TeX ON';
     ```
   - **Centralized function needed**:
     ```javascript
     function updateButtonVisualState(button, state) {
       const states = {
         'off': { tooltip: 'OFF - Click to toggle ON', text: '📐 TeX OFF' },
         'on': { tooltip: 'ON - Click to toggle OFF', text: '📐 TeX ON' },
         'api': { tooltip: 'API mode active', text: '📐 TeX API' },
         'simple': { tooltip: 'Simple mode active', text: '📐 TeX Simple' }
       };
       button.setAttribute('data-tooltip', states[state].tooltip);
       button.innerHTML = states[state].text;
       button.setAttribute('aria-pressed', state !== 'off');
     }
     ```
